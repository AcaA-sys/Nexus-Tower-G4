# 🗼 NEXUS-TOWER v6.0 Final


Nexus-Tower-G4 — это ультра-оптимизированный, высокоплотный интеллектуальный контроллер головы, разработанный для передовых многосопловых установочных модулей в экосистеме OpenPnP. Работая в жестких габаритах **49×100 мм**, эта плата функционирует как распределенный периферийный узел (Edge-node) в высокоскоростной сети CAN-FD, управляя сложной 6-осевой моторной матрицей и прецизионной пневматической телеметрией.

---

## Передовая архитектура и оптимизация

*   **100% утилизация выводов MCU:** Максимальное использование каждого аппаратного пина 64-выводного корпуса **STM32G431RBT6** за счет выноса всей вспомогательной сервисной логики на внешние сопроцессоры I2C.
*   **Честное независимое 6-осевое управление:** Полный отказ от объединенных линий направления (DIR) или программного «ногодрыга» (Bit-bang). Каждый моторный канал имеет выделенные, независимые аппаратные линии `STEP` и `DIR`, управляемые напрямую ядром `grblHAL`.
*   **Двухканальный аппаратный интерфейс UART:** Чтобы обойти аппаратное ограничение Trinamic на 4 устройства на одной однопроводной шине, 6-осевая матрица разделена между двумя независимыми аппаратными модулями USART:
    *   `USART1` (полудуплексный Single-Wire) – Выделен под 4 $\times$ оси вращения сопел (**C1–C4**).
    *   `USART3` (полудуплексный Single-Wire) – Выделен под 2 $\times$ вертикальные серво-оси (**Z1, Z2**).
*   **Двухосевая абсолютная система Closed-Loop:** Вертикальные оси **Z1** и **Z2** управляются через высокоскоростную аппаратную шину **SPI2**, непрерывно опрашивая абсолютные магнитные энкодеры (AS5047D / TLE5012B / MA730) на частоте **10 МГц** с нулевой нагрузкой на процессор. Симметричные аппаратные входы захвата (**PB0 / PB1**) фиксируют индексные метки ($Z$-marks) на лету, гарантируя абсолютную стабильность координат на скоростях до **3000 об/мин**.
*   **Разгрузка подсистем и помехоизоляция шины I2C:**
    *   **ADS1115IDGSR (16-битный АЦП):** Локализует прецизионные аналоговые измерения вакуума непосредственно в пневматическом хабе, полностью изолируя чувствительные микровольты от высокочастотных ШИМ-наводок драйверов моторов.
    *   **PCA9685 (16-канальный ШИМ-расширитель):** Управляет 8 $\times$ клапанами захвата/сброса вакуума, обеспечивает плавные эффекты «дыхания» статусных светодиодов с 12-битным аппаратным разрешением и регулирует обороты вентилятора охлаждения. Экономит 13 физических ног микроконтроллера.
*   **Тройной аппаратный рубеж безопасности:** Включает три независимые линии мгновенных аппаратных прерываний (**PC3, PC14, каналы EXTI**), работающие как наносекундный контур аварийного останова (E-Stop) для защиты от столкновений сопел при калибровке (Z-probe) и ударов каретки.

## Аппаратная карта пинов (STM32G431RBT6)

### 1. Моторная матрица (Управление 6 × TMC2226 и независимый Step/Dir)


| Контакт | Аппаратная функция | Описание сигнала |
| :--- | :--- | :--- |
| **PC4** | `USART1_TX` | `TMC_UART_C` – Шина Single-Wire Half-Duplex для осей вращения **C1–C4** (Адреса 0–3) |
| **PC5** | `USART1_RX` | `TMC_UART_C` – Общая петлевая линия обратной связи для осей вращения **C1–C4** |
| **PC10** | `USART3_TX` | `TMC_UART_Z` – Шина Single-Wire Half-Duplex для серво-осей **Z1–Z2** (Адреса 0–1) |
| **PC11** | `USART3_RX` | `TMC_UART_Z` – Общая петлевая линия обратной связи для вертикальных серво-осей **Z1–Z2** |
| **PC13** | `GPIO_Out` | `TMC_ENABLE_ALL` – Общий аппаратный сигнал разрешения работы силовых каскадов всех моторов |
| **PA8** | `GPIO_Out` | Ось вращения **C1**: Импульс шага `STEP` |
| **PA9** | `GPIO_Out` | Ось вращения **C1**: Управление направлением `DIR` |
| **PA10** | `GPIO_Out` | Ось вращения **C2**: Импульс шага `STEP` |
| **PB14** | `GPIO_Out` | Ось вращения **C2**: Управление направлением `DIR` |
| **PB15** | `GPIO_Out` | Ось вращения **C3**: Импульс шага `STEP` |
| **PC6** | `GPIO_Out` | Ось вращения **C3**: Управление направлением `DIR` |
| **PC7** | `GPIO_Out` | Ось вращения **C4**: Импульс шага `STEP` |
| **PC9** | `GPIO_Out` | Ось вращения **C4**: Управление направлением `DIR` |
| **PA1** | `GPIO_Out` | Вертикальная серво-ось **Z1**: Высокоскоростной импульс `STEP` |
| **PA6** | `GPIO_Out` | Вертикальная серво-ось **Z1**: Управление направлением `DIR` |
| **PA15** | `GPIO_Out` | Вертикальная серво-ось **Z2**: Высокоскоростной импульс `STEP` |
| **PB5** | `GPIO_Out` | Вертикальная серво-ось **Z2**: Управление направлением `DIR` |

### 2. Высокоскоростной контур обратной связи Closed-Loop


| Контакт | Аппаратная функция | Описание сигнала |
| :--- | :--- | :--- |
| **PB12** | `SPI2_NSS` / `GPIO_Out` | Абсолютный энкодер **Z1**: Выбор чипа `CS1` |
| **PA0** | `SPI2_NSS` / `GPIO_Out` | Абсолютный энкодер **Z2**: Выбор чипа `CS2` |
| **PB13** | `SPI2_SCK` | Высокоскоростная тактовая частота для абсолютных энкодеров (**10 МГц**) |
| **PB14** | `SPI2_MISO` | Общая линия приема данных – Ввод угловой фазы в MCU |
| **PB15** | `SPI2_MOSI` | Общая линия передачи данных – Отправка команд конфигурации в энкодеры |
| **PB0** | `TIM3_CH3` / `EXTI0` | Ось **Z1: Индексная метка ($Z$-Mark)** – Наносекундный аппаратный захват позиции |
| **PB1** | `TIM3_CH4` / `EXTI1` | Ось **Z2: Индексная метка ($Z$-Mark)** – Наносекундный аппаратный захват позиции |

### 3. Периферийная архитектура шины I2C (ADS1115 + PCA9685)


| Контакт | Аппаратная функция | Описание сигнала |
| :--- | :--- | :--- |
| **PB6** | `I2C1_SCL` | Магистральная шина: Управление **ADS1115**, **PCA9685**, EEPROM и OLED головы |
| **PB7** | `I2C1_SDA` | Магистральная шина: Управление **ADS1115**, **PCA9685**, EEPROM и OLED головы |
| **PC15** | `GPIO_Out` | `EEPROM_WP` – Аппаратная защита от записи таблиц калибровок и смещений сопел |
| **ADS1115** | `Устройство I2C` | Выделенный 16-битный АЦП для непрерывного опроса 4-х аналоговых датчиков вакуума |
| **PCA9685** | `Устройство I2C` | 16-Ch ШИМ: 4 $\times$ Клапана захвата, 4 $\times$ Клапана сброса, 3 $\times$ Светодиода, 1 $\times$ Вентилятор |
